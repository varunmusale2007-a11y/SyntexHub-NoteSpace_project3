# 📝 NoteSpace — Notes Management Website

**Organize your thoughts. Capture your ideas. Stay productive.**

NoteSpace is a modern, responsive notes management web application developed as a frontend web development project. It enables users to create, edit, search, organize, pin, and manage personal notes through a clean and intuitive interface.

## ✨ Features

- **Create Notes:** Add new notes with titles and content.
- **Edit Notes:** Update existing notes whenever needed.
- **Delete Notes:** Move unwanted notes to the Trash.
- **Search Notes:** Find notes quickly by searching titles and content.
- **Pin Important Notes:** Keep frequently used notes easily accessible.
- **Categories and Labels:** Organize notes by topic and color.
- **Autosave:** Save changes automatically, if enabled in the implementation.
- **Local Storage:** Preserve notes after refreshing or reopening the browser.
- **Recently Edited:** Quickly access recently modified notes.
- **Grid and List Views:** Switch between different layouts, if implemented.
- **Light and Dark Modes:** Choose a comfortable viewing theme.
- **Responsive Interface:** Use the application on desktops, tablets, and mobile devices.
- **Interactive Dashboard:** View note statistics and access features conveniently.

## 🛠️ Technologies Used

- **HTML5** — Website structure.
- **CSS3** — Styling, animations, layouts, and responsive design.
- **JavaScript (ES6+)** — Application logic and interactive functionality.
- **localStorage** — Browser-based data persistence.
- **Git and GitHub** — Version control and source-code hosting.
- **GitHub Pages** — Static website deployment.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- The Live Server extension for local development (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/SyntexHub-NoteSpace.git
   ```

2. Open the project folder:

   ```bash
   cd SyntexHub-NoteSpace
   ```

3. Open the folder in Visual Studio Code.

4. Run `index.html` using Live Server, or open it directly in your browser if the application supports it.

No Python, backend server, or database is required.

## 💻 How to Use

1. Open the NoteSpace website.
2. Click **New Note** to create a note.
3. Enter a title and your content.
4. Choose a category or label if available.
5. Save or edit your notes as needed.
6. Use search and filters to find specific notes.
7. Pin important notes for quick access.
8. Refresh the browser to verify that your notes are preserved.

## 🔒 Data and Privacy

Notes are stored locally in the browser when localStorage is used. They are not automatically synchronized across devices or browsers. Clearing browser storage may remove saved notes.

Avoid storing passwords or other sensitive information in the application.
